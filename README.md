# DigiLegends - MVP Build

Pacote com a base reestruturada e o primeiro loop jogável.

## Inclui
- bootstrap modular
- save local com versionamento simples
- novo jogo com nome do jogador
- escolha de starter
- home screen
- team screen
- DigiDex
- Hunts
- encounter system
- battle system inicial
- recompensa em Bits
- EXP e level up
- autosave

## Fluxo atual
1. Novo jogo
2. Escolha do starter
3. Menu principal
4. Abrir DigiDex / Team / Hunts
5. Selecionar uma hunt
6. Iniciar batalha
7. Atacar até vitória ou derrota
8. Receber recompensa e EXP
9. Save atualizado automaticamente
